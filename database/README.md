# Database Design & Schemas

This directory holds the database schemas, seed data, and migration scripts for MySQL.

## Database Engine
- **RDBMS**: MySQL 8.x
- **Integration**: To be connected via plain Java JDBC (no ORM frameworks like Hibernate/JPA).

## Planned Structure
When features are defined, add scripts here:
- `schema.sql` — Base tables, relations, and constraints.
- `seeds.sql` — Initial seed data for development.
- `migrations/` — Incremental versioned schema updates.

## Current Status
- No tables or connections configured yet.
- Schema definitions will be created once application data models are established.
